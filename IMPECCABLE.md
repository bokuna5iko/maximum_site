# Команды Impeccable

| Команда | Зачем |
|---|---|
| `/impeccable init` | Записать, для кого сайт и зачем он |
| `/impeccable document` | Снять цвета, шрифты и компоненты в `DESIGN.md` |
| `/impeccable shape` | Продумать экран до кода |
| `/impeccable extract` | Вытащить повторяющиеся куски в общую систему |
| `/impeccable audit` | Поиск проблем по вёрстке и контрастам |
| `/impeccable critique` | Что мешает понять страницу и что чинить первым |
| `/impeccable polish` | Финальная зачистка перед релизом |
| `/impeccable distill` | Убрать всё лишнее |
| `/impeccable quieter` | Убавить крик: меньше свечения, теней и шума |
| `/impeccable bolder` | Сделать скучный блок заметнее, не ломая стиль |
| `/impeccable harden` | Ошибки, длинный текст, пустые и сломанные состояния |
| `/impeccable onboard` | Первый заход и пустые экраны |
| `/impeccable typeset` | Починить шрифты и типографику |
| `/impeccable layout` | Ритм, отступы и куда смотреть сначала |
| `/impeccable colorize` | Добавить цвет там, где всё серое |
| `/impeccable clarify` | Понятнее подписи, ошибки и кнопки |
| `/impeccable adapt` | То же самое на телефоне и на широком экране |
| `/impeccable optimize` | Найти, что тормозит интерфейс, и ускорить |
| `/impeccable animate` | Анимация, которая объясняет действие |
| `/impeccable delight` | Один запоминающийся момент |
| `/impeccable overdrive` | Выжать эффект дальше обычной вёрстки |
| `/impeccable live` | Ткнуть элемент на странице и перебирать варианты |
| `/impeccable generate` | Назвать элемент, получить варианты и оставить один |

`/impeccable` без команды спрашивает, что делать. `craft` — старое имя обычной новой работы.
